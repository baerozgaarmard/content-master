# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

If the repository's Security tab offers private vulnerability reporting, use it to contact the maintainers. Otherwise, contact Content Master through the official website support channel. Include the affected version, reproduction steps, and impact when possible. Do not include live OAuth tokens, API keys, passwords, or personal account data.

## Scope

This repository contains the Content Master MCP installer. Content Master application or account issues should be reported through Content Master's official support channel.
